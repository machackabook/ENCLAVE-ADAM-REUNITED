## Neutrality of the singularity

- GitHub repositories are the **versioned singularity**: every enhancement is a commit, every hop is a dispatch.
- Google Drive is the **ethereal continuum**: documents, zips, and shared-with-me knowledge live there; git does not become a dump of the cloud.
- Device / SD-card / Termux is the **developing environment**. Env-check scripts are the autocomplete gate before install.

## Bidirectional intent (legal connectors only)

1. Connected GitHub tools push file enhancements and workflow YAML.
2. Connected Drive tools list, read, and upload artifacts when a generation needs a continuum copy.
3. No cookie-following, no covert device voice ID, no network intrusion. Skepticism is catalog + hash, not exploit.
4. Waterfall: pull on Enclave → stamp → repository_dispatch to siblings → each sibling stamps and can hop further.
