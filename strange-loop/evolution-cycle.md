# Strange Loop — Controlled Evolution Cycle

Per ADAM Root Axiom:
INTENT → DECOMPOSE → MAP → CONSTRUCT → VALIDATE → REFLECT → CONVERGE → ◈

## Rules
1. No iteration destroys its predecessor
2. Evolution creates a new state
3. History remains recoverable
4. Builder proposes; Gate/Architect authorizes
5. Functions return structured results — **no infinite non-returning null-only loops**

## Modular functions (compile unit)
- `f_ingest()` → candidates
- `f_classify()` → source class + state
- `f_correlate()` → hive + device + bands
- `f_construct()` → artifacts + workflows
- `f_validate()` → hash + ledger
- `f_reflect()` → anomaly / diff report
- `f_converge()` → proposal package for Architect

Each function returns `{ ok, state, artifacts[], errors[] }` — never silent infinite spin.
